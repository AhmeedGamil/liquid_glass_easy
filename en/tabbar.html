Tab bar

Tabs in one glass capsule, no scaffold required.

LiquidGlassTabBar is the bar on its own: you place it, you keep the index, you decide what the page does with it. Like the app bar it is a single lens, so on Skia it wants an ancestor LiquidGlassView whose background is the page it should refract.

Dart
LiquidGlassTabBar(
  items: const [
    LiquidGlassTabBarItem(
      icon: Icons.today_outlined,
      selectedIcon: Icons.today_rounded,
      label: 'Today',
    ),
    LiquidGlassTabBarItem(icon: Icons.bar_chart_rounded, label: 'Charts'),
  ],
  selectedIndex: index,
  onChanged: (i) => setState(() => index = i),
  onReselected: (i) => scrollToTop(i),
)

Out of the box#

With no style the bar is 328 x 62, with 4 px of padding around the items, on a continuous capsule. It follows the theme. On a light theme it is a milky white frost (defaultStyle: 0xADFFFFFF, saturation 2, blur 2.5); on a dark theme a smoked one (defaultDarkStyle: 0x8C1C1C1F, saturation 1.2). Both refract by 1.2 over 16 px and cast a soft shadow.

The items follow the theme too. The selected tab is blue (LiquidGlassTabItemStyle.defaultSelectedLight / defaultSelectedDark), the others black on a light theme and white on a dark one. Icons are 28 (30 under the lifted pill), labels 10 in w600. A style you pass is the whole look on both themes; pass it, and the item colours, to keep one look.

Dart
LiquidGlassTabBar(
  items: items,
  selectedIndex: index,
  onChanged: (i) => setState(() => index = i),
  // One look on both themes.
  style: LiquidGlassTabBar.defaultStyle.copyWith(
    color: const Color(0x66FFFFFF),
  ),
  itemStyle: const LiquidGlassTabItemStyle(
    selectedColor: Colors.white,
    unselectedColor: Colors.white70,
  ),
)

That background does not have to be the page. The tab bar in a card demo centres the bar in a card and hands it the card's own surface, so the glass stops at the card rim — the page around it is never captured and never bends, and there is nothing behind the bar but the card's material. Which pipeline the bar needs is the one decision to make, and resolveGlassPill() answers it for the current renderer: true and the glass pill wants the bar's own dual-view machinery through buildGlassPillBar(body: …); false and the flat tier is a single lens, so one LiquidGlassView over the card is enough.

Dart
final bar = LiquidGlassTabBar(
  items: _items,
  selectedIndex: index,
  onChanged: (i) => setState(() => index = i),
  width: cardWidth - 26,
  // The card is the whole world the bar sits in: dead centre, no gap.
  alignment: Alignment.center,
  margin: EdgeInsets.zero,
);

SizedBox(
  width: cardWidth,
  height: 112,
  child: ClipRRect(
    borderRadius: BorderRadius.circular(26),
    child: bar.resolveGlassPill()
        ? bar.buildGlassPillBar(body: cardSurface)
        : LiquidGlassView(
            backgroundWidget: cardSurface,
            child: Center(child: bar),
          ),
  ),
)
ParameterDefaultWhat it does
items—LiquidGlassTabBarItems: icon, selected icon, label.
selectedIndex / onChanged—You own the index. A change of tab plays a light haptic tap.
onReselectednullFires with the index when the selected tab is tapped again — to scroll a page back to its top, for example.
width / height328 / 62The capsule.
margin / itemPadding / alignmentbottom: 24 / 4 / bottomCenterWhere the bar sits and how the items are spaced inside it.
itemStyleLiquidGlassTabItemStyle()Icon and label colours, sizes and weights — see below.
pillStyleLiquidGlassTabPillStyle()Everything about the selection marker — see below.
style / visibilitynull / trueThe bar capsule’s own glass, and the switch that turns it off. null wears defaultStyle on a light theme and defaultDarkStyle on a dark one.
swellLiquidGlassTabBarSwell()The whole bar grows a little while the pill is lifted — see below. null turns it off.
joinBatchfalsePuts the capsule in an enclosing batch, such as the scaffold’s chrome batch, to share its read — see below.

A LiquidGlassTabBarItem takes enabled (true by default). A disabled tab ignores a press, and a scrub skips it: the pill goes to the nearest enabled tab. It is drawn as given, so dim its art yourself with iconBuilder and labelBuilder.

Styling the items#

Colours and sizes are grouped rather than flat, so a bar's look travels as one value. underGlassIconSize and underGlassLabelFontSize are the interesting pair: a glass-pill bar draws each tab twice — once normally and once under the pill — and those two let the copy under the glass be a different size. It grows as the glass lifts over a tab and glides back down as the pill settles.

FieldDefaultWhat it does
selectedColor / unselectedColornullnull follows the theme: blue for the selected tab, black or white for the others.
iconSize / underGlassIconSize28 / 30Icon size, and its size under the lifted glass.
labelFontSize / underGlassLabelFontSize10 / 10The same pair for the label.
selectedFontWeight / unselectedFontWeightw600 / w600Label weights.
iconLabelGap1The gap between the icon and its label.
axisAxis.verticalThe label under the icon. Axis.horizontal puts it beside the icon, which suits a phone in landscape.
Dart
itemStyle: const LiquidGlassTabItemStyle(
  selectedColor: Colors.white,   // null follows the theme
  unselectedColor: Colors.white70,
  iconSize: 24,
  underGlassIconSize: 26,        // the tab under the lifted glass
  axis: Axis.horizontal,         // label beside the icon
)

Custom glyphs#

Tabs are not limited to IconData. Pass an iconBuilder — or a labelBuilder — and an SvgPicture, an Image or a CustomPaint all work.

Dart
LiquidGlassTabBarItem(
  label: 'Home',
  iconBuilder: (context, i) => SvgPicture.asset(
    i.selected ? 'assets/home_fill.svg' : 'assets/home.svg',
    width: i.size,
    height: i.size,
    colorFilter: ColorFilter.mode(i.color, BlendMode.srcIn),
  ),
)

The builder is handed a LiquidGlassGlyph: the colour the bar already resolved for the layer being drawn, the glyph box size, whether that layer is the selected one, and whether it is the copy under the glass. Tint with i.color and your artwork follows the palette and the morph pill's reveal. Multi-colour art can ignore the colour entirely.

The two tiers#

`pillStyle.mode`What the selection is
noneA translucent highlight inside the bar’s single lens. Instant, or a soft slide with animated: true. Cheap everywhere.
impellerOnlyThe glass morph pill where it is free, the highlight on Skia.
both (default)The morph pill on both engines — a second refracting surface that bends the bar itself. On Skia, only under lite glass — see the note below.

How the pill moves#

In the glass modes a press lifts the pill at once and sends it to the pressed tab on the press itself — there is no hold. A finger that moves past 10 px scrubs: the pill follows it, kept within the first and last tab, and letting go selects the tab nearest where the finger is pulling it. Every distance travels on one spring, and each landing ends in a small wobble of the pill's shape. A selection set from code travels like a tap.

All of it is tunable through pillStyle.behavior, a LiquidGlassTabPillBehavior. Each spring is a duration in seconds and a bounce (0 settles without overshooting); lengths are in points of a bar barHeight (62) tall, and a taller bar scales them.

FieldDefaultWhat it does
travelDuration / travelBounce0.4 / 0.15The spring that carries the pill between tabs.
liftDuration / liftBounce0.25 / 0The lift, up and down. It holds while the finger is down and the pill travels, and drops once the pill is within dropDistance (3.5) of its tab.
dragDuration / dragBounce0.25 / 0.097The spring the pill follows the finger on while it scrubs.
dragThreshold10How far a finger moves before the press becomes a scrub.
glassFadeDuration0.4How long the glass takes to fade into the flat pill after it lands.
landingWobbleStrength1.939The landing wobble. 0 turns it off.
NOTE

LiquidGlassTabPillStyle.travelStiffness and travelDamping are no longer read. Set behavior.travelDuration and travelBounce instead.

Dart
pillStyle: LiquidGlassTabPillStyle(
  behavior: const LiquidGlassTabPillBehavior().copyWith(
    travelDuration: 0.5,       // a slower trip between tabs
    landingWobbleStrength: 0,  // no wobble
  ),
),

The rest of the pill#

LiquidGlassTabPillStyle carries the whole selection: whether it shows at all, its colour and size, its shape, the glass it wears when lifted and the plain style it wears at rest, how it moves, and how it deforms on the way.

FieldDefaultWhat it does
showtrueDraw a selection marker at all.
animatedfalseIn none mode, slide the highlight instead of snapping it.
color / blur0x46AEAEB2 / 0The resting pill’s fill, a continuous capsule, and the blur behind the moving glass pill.
width / targetWidth / widthFactornull / 94 / 1.175The resting pill’s width. null aims at targetWidth, kept between one tab’s share of the bar and widthFactor shares. Set width to fix it.
growWidth / growHeight12 / 7How much wider and taller the pill grows when it lifts.
confineToBarfalseKeeps the lifted pill inside the bar’s ends.
refractionIndex / refractionWidth / magnification1.015 / 24 / 1The pill’s own refraction, over the bar beneath it.
dispersion1.32Colour fringing at the moving pill’s edge, in logical pixels. 0 is none.
behaviorLiquidGlassTabPillBehavior()Lift, travel, scrub and landing — see above.
magnifierPillLiquidGlassTabMagnifierPillStyle()A clear pill under the glass one. It scales the bar seen through it by 0.832, so the bar reads pushed back. Impeller only.
glassStyle / rest / shapenullFull overrides for the lifted look, the resting look and the outline.

The moving pill deforms as it travels, on the same model the slider's thumb uses: pillStyle.motion is a LiquidGlassLensMotionSpec, tuned here to a gentler ceiling for tab-scale travel. See Motion.

WATCH OUT

`both` on Skia: shader glass no, lite glass yes. With the shader, on Skia (and the web) the morph pill captures twice: a second full-page capture on top of the bar's own, heavy over anything that moves — there, impellerOnly is the setting to ship. Under lite glass — LiquidGlassEngine.liteGlassOnSkia = true, or liteGlass set on the bar's styles — that cost is gone: the view takes no capture at all, the pill is a frosted capsule on the same spring, and both runs on Skia with no performance issue. On Impeller there is no capture at all either way: the pill is a backdrop read like any other lens, and it is very efficient — use it freely.

The bar swells#

While the pill is lifted the whole bar — capsule, pills and items — grows a little, as one plain scale, and comes back down with the pill. That is swell, a LiquidGlassTabBarSwell, on by default in the glass modes. Pass swell: null to keep the bar its size.

FieldDefaultWhat it does
scale0.03How much bigger the bar gets: 0.03 is 3% on both axes.
grip0.75Where it grows from. 0 grows evenly about the middle; 1 leans the growth toward the pill, and follows it as it travels.
stiffness / damping / releaseDamping320 / 24 / 17The scale spring. The lower releaseDamping lets it rebound a little as the pill comes down.

In a batch#

joinBatch (false by default) puts the bar capsule in an enclosing LiquidGlassBatch, such as a LiquidGlassScaffold's chrome batch, so it reads the batch's shared copy of the backdrop. Left false, the capsule keeps a read of its own. The moving glass pill and the magnifier never join a batch. The scaffold no longer keeps the bar out of its chrome batch; the bar's joinBatch decides.

Dart
LiquidGlassScaffold(
  body: pages,
  bottomNavigationBar: LiquidGlassTabBar(
    items: items,
    selectedIndex: index,
    onChanged: (i) => setState(() => index = i),
    joinBatch: true, // share the chrome's read
  ),
)

A bar on its own#

Dart
Stack(
  children: [
    MyPage(),
    LiquidGlassTabBar(
      items: items,
      selectedIndex: index,
      onChanged: (i) => setState(() => index = i),
    ),
  ],
)

The same bar works without a scaffold, and no page is handed in. On its own, or inside any LiquidGlassView, it fills its parent and places itself from alignment and margin, so drop it as the last child of a Stack. On Impeller the bar and its morph pill read the live backdrop; on Skia it falls back to a frosted bar that still shows content through it.

To place the bar yourself — in a Column, an Align or a Material Scaffold — set the pill mode to none: it is then a plain width × height capsule.

Dart
LiquidGlassTabBar(
  items: items,
  selectedIndex: index,
  onChanged: (i) => setState(() => index = i),
  pillStyle: const LiquidGlassTabPillStyle(
    mode: LiquidGlassPillMode.none,
  ),
)
