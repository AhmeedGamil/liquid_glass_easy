شريط التبويبات

تبويبات في كبسولة زجاجية واحدة، بلا حاجة إلى هيكل.

LiquidGlassTabBar هو الشريط وحده: أنت تضعه، وأنت تحفظ الفهرس، وأنت تقرّر ما تفعله الصفحة به. وهو كالشريط العلوي عدسةٌ واحدة، فيريد على Skia LiquidGlassView أباً خلفيته هي الصفحة التي ينبغي أن يكسرها.

Dart
LiquidGlassTabBar(
  items: const [
    LiquidGlassTabBarItem(
      icon: Icons.today_outlined,
      selectedIcon: Icons.today_rounded,
      label: 'Today',
    ),
    LiquidGlassTabBarItem(icon: Icons.bar_chart_rounded, label: 'Charts'),
  ],
  selectedIndex: index,
  onChanged: (i) => setState(() => index = i),
  onReselected: (i) => scrollToTop(i),
)

كما يأتي#

بلا style يكون الشريط 328 x 62، مع 4 بكسل حول العناصر، على كبسولة متصلة الزوايا. وهو يتبع السمة. فعلى السمة الفاتحة صقيعٌ أبيض حليبي (defaultStyle: 0xADFFFFFF، وتشبّع 2، وضبابية 2.5)، وعلى السمة الداكنة صقيعٌ مدخَّن (defaultDarkStyle: 0x8C1C1C1F، وتشبّع 1.2). وكلاهما يكسر بمقدار 1.2 على 16 بكسل ويُلقي ظلاً ناعماً.

والعناصر تتبع السمة كذلك. فالتبويب المحدَّد أزرق (LiquidGlassTabItemStyle.defaultSelectedLight / defaultSelectedDark)، والبقية أسود على السمة الفاتحة وأبيض على الداكنة. والأيقونات 28 (و30 تحت الحبة المرفوعة)، والنصوص 10 بوزن w600. والـstyle الذي تمرّره هو المظهر كله على السمتين؛ فمرّره، ومعه ألوان العناصر، لتُبقي مظهراً واحداً.

Dart
LiquidGlassTabBar(
  items: items,
  selectedIndex: index,
  onChanged: (i) => setState(() => index = i),
  // One look on both themes.
  style: LiquidGlassTabBar.defaultStyle.copyWith(
    color: const Color(0x66FFFFFF),
  ),
  itemStyle: const LiquidGlassTabItemStyle(
    selectedColor: Colors.white,
    unselectedColor: Colors.white70,
  ),
)

ليس شرطاً أن تكون تلك الخلفية هي الصفحة. فعرض الشريط داخل بطاقة يتوسّط بالشريط بطاقةً ويسلّمه سطحَ البطاقة نفسه، فيقف الزجاج عند حافتها — أما الصفحة حولها فلا تُلتقط ولا تنكسر، وليس خلف الشريط سوى مادة البطاقة. والقرار الوحيد هو أيّ مسار يحتاجه الشريط، وresolveGlassPill() يجيب عنه على المُصيِّر الحالي: صحيح فتريد الحبةُ الزجاجية آلةَ الشريط ذات العرضين عبر buildGlassPillBar(body: …)، وخطأ فالمستوى المسطّح عدسةٌ واحدة، ويكفيه LiquidGlassView واحد فوق البطاقة.

Dart
final bar = LiquidGlassTabBar(
  items: _items,
  selectedIndex: index,
  onChanged: (i) => setState(() => index = i),
  width: cardWidth - 26,
  // The card is the whole world the bar sits in: dead centre, no gap.
  alignment: Alignment.center,
  margin: EdgeInsets.zero,
);

SizedBox(
  width: cardWidth,
  height: 112,
  child: ClipRRect(
    borderRadius: BorderRadius.circular(26),
    child: bar.resolveGlassPill()
        ? bar.buildGlassPillBar(body: cardSurface)
        : LiquidGlassView(
            backgroundWidget: cardSurface,
            child: Center(child: bar),
          ),
  ),
)
المعاملالافتراضيما يفعله
items—عناصر LiquidGlassTabBarItem: أيقونة وأيقونة محدَّدة ونص.
selectedIndex / onChanged—الفهرس ملكك. وتغيير التبويب يُصدر نقرة اهتزاز خفيفة.
onReselectednullيُطلَق بالفهرس حين يُنقر التبويب المحدَّد مرة أخرى — لإعادة الصفحة إلى أعلاها مثلاً.
width / height328 / 62الكبسولة.
margin / itemPadding / alignmentbottom: 24 / 4 / bottomCenterأين يجلس الشريط وكيف تتباعد العناصر بداخله.
itemStyleLiquidGlassTabItemStyle()ألوان الأيقونات والنصوص ومقاساتها وأوزانها — انظر أدناه.
pillStyleLiquidGlassTabPillStyle()كل ما يخصّ علامة التحديد — انظر أدناه.
style / visibilitynull / trueزجاج كبسولة الشريط نفسه، والمفتاح الذي يطفئه. وnull يلبس defaultStyle على السمة الفاتحة وdefaultDarkStyle على الداكنة.
swellLiquidGlassTabBarSwell()يكبر الشريط كله قليلاً ما دامت الحبة مرفوعة — انظر أدناه. وnull يطفئه.
joinBatchfalseيضع الكبسولة في دفعة محيطة بها، كدفعة عناصر الهيكل، لتتشارك قراءتها — انظر أدناه.

يأخذ LiquidGlassTabBarItem المعامل enabled (true افتراضياً). فالتبويب المعطَّل يتجاهل الضغط، ويتخطّاه السحب: فتذهب الحبة إلى أقرب تبويب مفعَّل. ويُرسم كما أُعطي، فخفّف رسمه بنفسك عبر iconBuilder وlabelBuilder.

تنسيق العناصر#

الألوان والمقاسات مجمَّعة لا مسطّحة، فينتقل مظهر الشريط كقيمة واحدة. وunderGlassIconSize وunderGlassLabelFontSize هما الزوج اللافت: فالشريط ذو الحبة الزجاجية يرسم كل تبويب مرتين — مرة عادية ومرة تحت الحبة — ويتيح هذان أن تكون النسخة التي تحت الزجاج بمقاس مختلف. فتكبر حين يرتفع الزجاج فوق التبويب، وتنزل بهدوء حين تستقر الحبة.

الحقلالافتراضيما يفعله
selectedColor / unselectedColornullnull يتبع السمة: أزرق للتبويب المحدَّد، وأسود أو أبيض للبقية.
iconSize / underGlassIconSize28 / 30مقاس الأيقونة، ومقاسها تحت الزجاج المرفوع.
labelFontSize / underGlassLabelFontSize10 / 10الزوج نفسه للنص.
selectedFontWeight / unselectedFontWeightw600 / w600أوزان النص.
iconLabelGap1الفجوة بين الأيقونة ونصّها.
axisAxis.verticalالنص تحت الأيقونة. وAxis.horizontal يضعه بجانبها، وهذا يناسب الهاتف في الوضع الأفقي.
Dart
itemStyle: const LiquidGlassTabItemStyle(
  selectedColor: Colors.white,   // null follows the theme
  unselectedColor: Colors.white70,
  iconSize: 24,
  underGlassIconSize: 26,        // the tab under the lifted glass
  axis: Axis.horizontal,         // label beside the icon
)

رموز مخصصة#

التبويبات ليست محصورة في IconData. مرّر iconBuilder — أو labelBuilder — فتعمل SvgPicture وImage وCustomPaint جميعها.

Dart
LiquidGlassTabBarItem(
  label: 'Home',
  iconBuilder: (context, i) => SvgPicture.asset(
    i.selected ? 'assets/home_fill.svg' : 'assets/home.svg',
    width: i.size,
    height: i.size,
    colorFilter: ColorFilter.mode(i.color, BlendMode.srcIn),
  ),
)

يُسلَّم البنّاء LiquidGlassGlyph: اللون الذي حسمه الشريط للطبقة المرسومة، ومقاس صندوق الرمز، وهل هذه الطبقة هي المحدَّدة، وهل هي النسخة التي تحت الزجاج. لوّن بـ i.color فيتبع رسمُك اللوحةَ وكشفَ الحبة المتحولة. أما الرسم متعدد الألوان فيمكنه تجاهل اللون تماماً.

المستويان#

`pillStyle.mode`ما هو التحديد
noneإبراز شفاف داخل عدسة الشريط الواحدة. فوري، أو انزلاق ناعم مع animated: true. ورخيص في كل مكان.
impellerOnlyالحبة المتحولة الزجاجية حيث تكون مجانية، والإبراز على Skia.
both (الافتراضي)الحبة المتحولة على المحركين — سطح كاسر ثانٍ يثني الشريط نفسه. وعلى Skia تحت الزجاج الخفيف فقط — انظر الملاحظة أدناه.

كيف تتحرك الحبة#

في الأوضاع الزجاجية يرفع الضغطُ الحبةَ فوراً ويرسلها إلى التبويب المضغوط مع الضغطة نفسها — بلا انتظار. والإصبع الذي يتحرك أكثر من 10 بكسل يسحب: فتتبعه الحبة، محصورةً بين التبويب الأول والأخير، وعند الإفلات يُحدَّد التبويب الأقرب إلى حيث يشدّها الإصبع. وكل مسافة تُقطع على نابض واحد، وتنتهي كل هبطة بتمايل صغير في شكل الحبة. والتحديد المضبوط من الكود يسافر كالنقرة.

وكل ذلك قابل للضبط عبر pillStyle.behavior، وهو LiquidGlassTabPillBehavior. فكل نابض مدةٌ بالثواني وارتداد (0 يستقر بلا تجاوز)، والأطوال بنقاط شريط ارتفاعه barHeight (62)، والشريط الأطول يكبّرها.

الحقلالافتراضيما يفعله
travelDuration / travelBounce0.4 / 0.15النابض الذي يحمل الحبة بين التبويبات.
liftDuration / liftBounce0.25 / 0الرفع صعوداً ونزولاً. ويثبت ما دام الإصبع نازلاً والحبة مسافرة، وينزل حين تصير الحبة على بعد dropDistance (3.5) من تبويبها.
dragDuration / dragBounce0.25 / 0.097النابض الذي تتبع به الحبة الإصبع أثناء السحب.
dragThreshold10المسافة التي يتحركها الإصبع قبل أن يصير الضغط سحباً.
glassFadeDuration0.4المدة التي يستغرقها الزجاج ليتلاشى في الحبة المسطّحة بعد هبوطها.
landingWobbleStrength1.939تمايل الهبوط. و0 يطفئه.
ملاحظة

لم يعد LiquidGlassTabPillStyle.travelStiffness وtravelDamping يُقرآن. اضبط behavior.travelDuration وtravelBounce بدلاً منهما.

Dart
pillStyle: LiquidGlassTabPillStyle(
  behavior: const LiquidGlassTabPillBehavior().copyWith(
    travelDuration: 0.5,       // a slower trip between tabs
    landingWobbleStrength: 0,  // no wobble
  ),
),

بقية الحبة#

يحمل LiquidGlassTabPillStyle التحديد كله: هل يظهر أصلاً، ولونه ومقاسه، وشكله، والزجاج الذي يلبسه مرفوعاً والأسلوب البسيط الذي يلبسه ساكناً، وكيف يتحرك، وكيف يتشوّه في الطريق.

الحقلالافتراضيما يفعله
showtrueرسم علامة تحديد من الأساس.
animatedfalseفي وضع none، انزلاق الإبراز بدل قفزه.
color / blur0x46AEAEB2 / 0تعبئة الحبة الساكنة، وهي كبسولة متصلة الزوايا، والضبابية خلف الحبة الزجاجية المتحركة.
width / targetWidth / widthFactornull / 94 / 1.175عرض الحبة الساكنة. وnull يقصد targetWidth، محصوراً بين حصة تبويب واحد من الشريط وwidthFactor حصص. واضبط width لتثبيته.
growWidth / growHeight12 / 7كم تزيد الحبة عرضاً وارتفاعاً حين ترتفع.
confineToBarfalseيُبقي الحبة المرفوعة داخل طرفَي الشريط.
refractionIndex / refractionWidth / magnification1.015 / 24 / 1انكسار الحبة نفسها، فوق الشريط تحتها.
dispersion1.32تهدّب الألوان عند حافة الحبة المتحركة، بالبكسل المنطقي. و0 لا شيء.
behaviorLiquidGlassTabPillBehavior()الرفع والسفر والسحب والهبوط — انظر أعلاه.
magnifierPillLiquidGlassTabMagnifierPillStyle()حبة شفافة تحت الزجاجية. تحجّم الشريط المرئي عبرها بمقدار 0.832، فيبدو الشريط مدفوعاً إلى الخلف. على Impeller فقط.
glassStyle / rest / shapenullتجاوزات كاملة لمظهر الرفع ومظهر السكون والمحيط.

تتشوّه الحبة المتحركة أثناء سفرها، بالنموذج نفسه الذي يستخدمه مقبض المزلاج: فـpillStyle.motion هو LiquidGlassLensMotionSpec، مضبوط هنا بسقف أرفق لمسافة التبويبات. انظر الحركة.

انتبه

`both` على Skia: لا مع الشيدر، نعم مع الزجاج الخفيف. فمع الشيدر تلتقط الحبة المتحولة على Skia (والويب) مرتين: التقاط ثانٍ للصفحة كلها فوق التقاط الشريط نفسه، ثقيل فوق أي شيء يتحرك — وهناك يكون impellerOnly هو الإعداد الذي تشحنه. أما تحت الزجاج الخفيف — LiquidGlassEngine.liteGlassOnSkia = true، أو ضبط liteGlass على أنماط الشريط — فتزول تلك الكلفة: لا يلتقط العارض شيئاً إطلاقاً، والحبة كبسولة مصقّعة على النابض نفسه، ويعمل both على Skia بلا أي مشكلة في الأداء. وعلى Impeller لا التقاط إطلاقاً في الحالتين: الحبة قراءة خلفية كأي عدسة، وهي فعّالة جداً — فاستخدمها بلا تردد.

الشريط ينتفخ#

ما دامت الحبة مرفوعة يكبر الشريط كله — الكبسولة والحبّات والعناصر — قليلاً، بتحجيم واحد بسيط، ثم يعود مع الحبة. هذا هو swell، وهو LiquidGlassTabBarSwell، مفعَّل افتراضياً في الأوضاع الزجاجية. ومرّر swell: null ليبقى الشريط بمقاسه.

الحقلالافتراضيما يفعله
scale0.03مقدار ما يكبر الشريط: 0.03 تعني 3% على المحورين.
grip0.75من أين يكبر. 0 يكبر بالتساوي حول المنتصف، و1 يميل بالنمو نحو الحبة، ويتبعها وهي تسافر.
stiffness / damping / releaseDamping320 / 24 / 17نابض التحجيم. وreleaseDamping الأدنى يتركه يرتد قليلاً حين تنزل الحبة.

داخل دفعة#

يضع joinBatch (false افتراضياً) كبسولةَ الشريط في LiquidGlassBatch محيطة بها، كدفعة عناصر LiquidGlassScaffold، فتقرأ نسخة الدفعة المشتركة من الخلفية. وإن تُرك false احتفظت الكبسولة بقراءة خاصة بها. أما الحبة الزجاجية المتحركة والمكبِّر فلا ينضمّان إلى دفعة أبداً. ولم يعد الهيكل يُبقي الشريط خارج دفعة عناصره؛ فـjoinBatch في الشريط هو الذي يقرّر.

Dart
LiquidGlassScaffold(
  body: pages,
  bottomNavigationBar: LiquidGlassTabBar(
    items: items,
    selectedIndex: index,
    onChanged: (i) => setState(() => index = i),
    joinBatch: true, // share the chrome's read
  ),
)

شريط وحده#

Dart
Stack(
  children: [
    MyPage(),
    LiquidGlassTabBar(
      items: items,
      selectedIndex: index,
      onChanged: (i) => setState(() => index = i),
    ),
  ],
)

الشريط نفسه يعمل بلا هيكل، ولا تُسلَّم إليه صفحة. فوحده، أو داخل أي LiquidGlassView، يملأ أباه ويضع نفسه وفق alignment وmargin، فضعه آخر ابن في Stack. على Impeller يقرأ الشريط وحبته المتحولة الخلفية الحية؛ وعلى Skia يتراجع إلى شريط مصنفر يظل يُظهر المحتوى عبره.

ولتضع الشريط بنفسك — في Column أو Align أو Scaffold من Material — اضبط mode الحبة على none: فيصير كبسولة عادية بمقاس width × height.

Dart
LiquidGlassTabBar(
  items: items,
  selectedIndex: index,
  onChanged: (i) => setState(() => index = i),
  pillStyle: const LiquidGlassTabPillStyle(
    mode: LiquidGlassPillMode.none,
  ),
)
